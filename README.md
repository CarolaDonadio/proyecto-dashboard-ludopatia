# 📊 Proyecto Dashboard — Ludopatía en Adolescentes

> Proyecto de Matemáticas y Ciencia de Datos orientado a la creación de un **dashboard web interactivo** para visualizar y analizar resultados de encuestas sobre ludopatía en adolescentes.

---

## 🚀 Demo en línea
Accede al proyecto desplegado en Vercel:  
👉 [proyecto-dashboard-ludopatia.vercel.app](https://proyecto-dashboard-ludopatia.vercel.app)

---

## 📁 Estructura del repositorio
```text
proyecto-dashboard-ludopatia/
├── dashboard.html      # Página principal del dashboard
├── index.html          # Landing page con pop-up de advertencia
├── login.html          # Pantalla de inicio de sesión
├── css/                # Estilos (responsive)
├── js/                 # Scripts (pop-ups, dinámicas)
├── img/                # Recursos gráficos
├── Preguntas del Formulario.docx # Encuesta base
└── README.md           # Documentación del proyecto
```

---

## 🛠️ Tecnologías utilizadas
- **HTML5** — estructura semántica
- **CSS3** — diseño responsive
- **JavaScript** — interactividad y validaciones
- **Vercel** — despliegue en producción

---

## 📌 Funcionalidades principales
- **Encuesta anónima** sobre ludopatía en adolescentes.
- **Dashboard interactivo** para visualizar resultados.
- **Pop-up de advertencia** para concientizar al usuario.
- **Login básico** con primeros diseños de autenticación.
- **Diseño responsive** para distintos dispositivos.

---

## 📊 Objetivo del proyecto
El propósito es **analizar y concientizar** sobre la problemática de la ludopatía en adolescentes mediante el uso de herramientas de ciencia de datos y visualización web.
